## ECサイト利益向上のための顧客分析
コード: ecommerce_analysis.ipynb
### 目標
ECサイトの利益向上につながる顧客行動を分析し、施策を提案する。
### 説明
BigQuery Public Datasetのthelook_ecommerceを使用し、利益向上を目的として顧客属性・購買行動・継続率を分析した。EDA分析、RFM分析、コホート分析を通じて課題を特定し、施策提案を行った。
### 分析フロー
デモグラフィックの確認
→
EDA
→
RFM
→
コホート
→
施策提案

---

### EDA分析
男女別の購入カテゴリを分析した結果、購入傾向に違いが見られた。

男性はアウターやジーンズなどのカテゴリを多く購入している一方、女性はインナーやファッション関連商品の購入が多い傾向が確認された。

このことから、性別ごとにレコメンド商品やキャンペーン内容を最適化することで、購入率向上が期待できる。

### RFM分析
RFM分析の結果、全顧客の76.1%が初回購入のみであることが分かった。

また、VIP顧客は購入頻度が高く、一人当たり利益も優良顧客の約2倍となっていた。

一方で、一般顧客、優良顧客の人数はVIP顧客より多い。その中でも

- 一般顧客→優良顧客にランクアップした場合の利益増加：12.9$
- 優良顧客→VIP顧客にランクアップした場合の利益増加：58.3$

以上のように優良顧客をVIP顧客にランクアップさせたときの利益増加が大きいことがわかった。

このことから、優良顧客に向けた施策を考えることで、利益向上が期待できる。

このことから、VIP顧客が好む商品カテゴリを参考にレコメンド施策を実施することで、顧客単価や購入頻度の向上につながる可能性がある。

---

### コホート分析

コホート分析の結果、約90%の顧客が初回購入から1ヶ月以内に離脱していることが分かった。

一方で、2ヶ月目以降の継続率は比較的安定しており、初回購入直後の定着が重要な課題であると考えられる。

このことから、初回購入者向けクーポンやメール配信などのフォロー施策を実施し、2回目購入を促進することが利益向上につながると考えられる。

### 結果
本分析では、優良顧客のVIP化と初回購入者の定着率向上が利益向上における重要な課題であることが分かった。特にVIP顧客は一人当たり利益が高く、優良顧客からVIP顧客への育成効果が大きい。今後はVIP顧客が好むカテゴリの強化と、初回購入者へのフォロー施策を実施することで、利益向上が期待できる。
